HTML

01

Estrutura o conteúdo. Tags como h1, p e button representam título, parágrafo e botão.

<h1>Olá, mundo!</h1>
<p>Meu primeiro site.</p>
<button>Começar</button>

CSS

02

Define a aparência. Seletores escolhem elementos; propriedades definem cores, espaços e tamanhos.

h1 {
  color: #6530a4;
  font-size: 32px;
}

JavaScript

03

Adiciona comportamento. const guarda um valor; function define uma ação reutilizável.

const nome = "Ana";
function saudacao(pessoa) {
  return "Olá, " + pessoa;
}
console.log(saudacao(nome));

Python

04

Ajuda a criar scripts e automações. def cria uma função; print mostra uma mensagem.

    return "Olá, " + nome
